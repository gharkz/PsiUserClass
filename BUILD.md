# Build (PSI User Class)

Run `dotnet build -c Release`. Set the `ElinGamePath` MSBuild property if Elin is installed elsewhere.

The build does not install anything. The package in `dist/PsionClass` needs its DLL, `package.xml`, `assets/` and `LangMod/` together.

Release version: 0.2.0 (beta). Package compatibility: 0.23.355.

All Psion rows (job, Psicraft skill, feats, kinetic power clones, Psi-Shield, Psi-Teleport, Psi-Hurl, Psi-Strike, Necropathy enchant, tactics) are registered in code by cloning vanilla rows; nothing depends on other mods. Custom act classes live in the global namespace and are resolved through a `ClassCache.typeLoaders` entry. Icons and the Workshop preview are original and generated by `tools/draw_icons.py` and `tools/draw_preview.py`.
